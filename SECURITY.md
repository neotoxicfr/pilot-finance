# Security Policy

## Supported Versions

Only the latest minor release receives security fixes.

| Version | Supported |
| ------- | --------- |
| v2.9.x  | ✅ |
| < v2.9  | ❌ |

> Versions prior to v2.9 are no longer supported. Please update to the latest release.

## Reporting a Vulnerability

If you discover a security vulnerability, **do not open a public issue**.

Contact me privately:
* **Discord**: neo_sportbike

I aim to respond within 48 hours to discuss remediation steps.

# Politique de Sécurité

## Versions supportées

Seule la dernière version mineure bénéficie des correctifs de sécurité.

| Version | Supportée |
| ------- | --------- |
| v2.9.x  | ✅ |
| < v2.9  | ❌ |

> Les versions antérieures à v2.9 ne sont plus supportées. Veuillez mettre à jour vers la dernière version.

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité, **ne pas ouvrir d'issue publique**.

Contactez-moi en privé :
* **Discord** : neo_sportbike

Je m'efforce de répondre sous 48 heures pour discuter des étapes de correction.
