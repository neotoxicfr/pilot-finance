# Contributing to Pilot Finance

Thank you for your interest! As this is a personal project, here's how to contribute:

1. **Open an Issue first** — Discuss the change you want to make before writing code.
2. **Pull Request** — Submit your changes on a separate branch. Make sure the Docker build passes cleanly.
3. **Code standards** — Follow the existing Go patterns (chi handlers, HTMX partials, Alpine.js for client state). Avoid introducing external JS/CSS dependencies.
4. **Security** — Never commit `.env` files, databases, or encryption keys.

# Contribuer à Pilot Finance

Merci de votre intérêt ! Comme il s'agit d'un projet personnel, voici la marche à suivre :

1. **Ouvrir une Issue d'abord** — Discutez du changement souhaité avant de coder.
2. **Pull Request** — Soumettez vos modifications sur une branche séparée. Assurez-vous que le build Docker passe sans erreur.
3. **Standards de code** — Respectez les patterns Go existants (handlers chi, partials HTMX, Alpine.js pour l'état client). Évitez d'introduire de nouvelles dépendances JS/CSS externes.
4. **Sécurité** — Ne commitez jamais de fichiers `.env`, de bases de données ou de clés de chiffrement.
